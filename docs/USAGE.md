# How to use Duo Wallet

Short companion to the [README](../README.md). In the app: **Settings → Help**.

## First launch

1. Enter your Supabase project URL and publishable key (or use a build that already has them).
2. Sign up with your name, email and password.
3. Add at least one **account** (M-Pesa, M-Shwari, Ziidi, Pochi, bank, cash) and its **opening balance**.

## Share with your partner

1. Settings → **Household** → create a household.
2. Copy or share the **invite code**.
3. Partner installs the APK, signs up, joins with the code.
4. Switch between **Personal** and the household from the ledger button on Home.

## Log money

Tap **+**:

- **Paste M-Pesa SMS** — fills amount, transaction cost, confirmation code, and date/time automatically
- Then pick the **category** (Fuliza → debt/loan; M-Shwari/Ziidi → savings; Pochi → business — suggestions only)
- **Other** requires you to say what it is
- Or type amounts yourself; fees are always spending

## Import from inbox (Android)

Settings → Import M-Pesa. SMS permission is optional. Messages are grouped by confirmation code (Fuliza doubles become one). You categorise each before save.

## Appearance

Settings → Appearance: light/dark, colour themes (Midnight, Emerald, Ocean, Sand, Rose, Slate), fonts (DM Sans, Source Serif, Nunito, Fraunces).

## Reports & help

- Insights → **Share PDF report** for AI / partner advice
- Settings → Help → Usage guide, FAQ, Terms, Privacy

## Salary, debts, budgets

| Screen | Path |
| --- | --- |
| Salary & fixed bills | Settings → Salary & bills |
| Debts | Settings → Debts |
| Budgets | Settings → Budgets |

Salary posts automatically on its day of the month.
